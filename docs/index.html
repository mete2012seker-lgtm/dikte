Windows SmartScreen ("Kişisel bilgisayarınızı korudu") uyarısı neden çıkar?

Dikte ücretsiz bir açık kaynak projedir ve kurucu dosya henüz ücretli bir kod imzalama sertifikasıyla imzalanmamıştır. İlk kurulumda Windows mavi uyarı penceresi gösterirse Ek bilgi → Yine de çalıştır adımıyla devam edebilirsin. İstersen indirdiğin kurucuyu PowerShell'de şu komutla doğrulayıp yukarıdaki SHA-256 ile karşılaştırabilirsin:

Get-FileHash .\Dikte-Setup-1.6.1.exe -Algorithm SHA256

Sık Sorulan Sorular

Güçlü bir ekran kartım (NVIDIA GPU) olması şart mı?

Hayır. NVIDIA ekran kartı varsa CUDA ile çok hızlı çalışır; yoksa uygulama otomatik olarak işlemci (CPU) moduna geçer. Küçük modeller (Tiny / Small) standart dizüstü bilgisayarlarda rahatlıkla çalışır.

Konuşmalarım internet üzerinden bir yere gönderiliyor mu?

Varsayılan olarak hayır. Ses tanıma tamamen bilgisayarında yapılır. Yalnızca sen Ayarlar'dan kendi OpenRouter API anahtarını girip bulut temizleme/çeviri açarsan metin o sağlayıcıya gönderilir.

Beğenmezsem bilgisayardan tamamen nasıl kaldırırım?

Ayarlar → Uygulamayı Kaldır düğmesiyle (veya Windows Uygulamalar menüsünden) temizce kaldırabilirsin. Kaldırırken büyük model dosyalarını koruma veya tamamen silme seçeneği sunulur.

Bir hata alırsam nasıl bildirebilirim?

Ayarlar → Sorun Giderme ve Tanılama bölümünden veya sistem tepsisi menüsünden "Tanılama Raporu Kopyala" butonuna basıp GitHub Issues sayfasında paylaşabilirsin. Rapor konuşma metni ve API anahtarı içermez.
