Why does Windows SmartScreen ("Windows protected your PC") appear?

Dikte is a free open-source project and the installer is not yet signed with a paid code-signing certificate. If Windows displays a blue warning on first run, click More info → Run anyway to continue. You can also verify the installer in PowerShell with this command and compare it against the SHA-256 checksum above:

Get-FileHash .\Dikte-Setup-1.6.1.exe -Algorithm SHA256

Frequently Asked Questions

Do I need a powerful NVIDIA GPU?

No. If you have an NVIDIA GPU, Dikte uses CUDA for ultra-fast transcription; otherwise it automatically falls back to CPU mode. Lighter models (Tiny / Small) run smoothly on standard laptops.

Is my speech ever sent over the internet?

Not by default. Speech recognition happens completely locally on your PC. Text is only sent externally if you enter your own OpenRouter API key in Settings and enable cloud cleanup or translation.

How do I completely uninstall it if I change my mind?

Use Settings → Uninstall App inside Dikte (or Windows Installed Apps) for a clean removal. During uninstall, you can choose whether to keep or delete large model files.

How can I report a bug?

Click "Copy Diagnostic Report" from Settings → Troubleshooting & Diagnostics (or the system tray menu) and paste it on GitHub Issues. The report never includes your dictated text or API keys.
